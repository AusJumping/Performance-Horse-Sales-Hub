You are an expert full-stack developer, workflow architect, and AI automation builder.

I want you to build the post-submission workflow for a horse sales business called Performance Horse Sales Australia and New Zealand.

This project already has an existing seller submission form. The content of that form is fixed and must not be changed. Do not add, remove, rename, merge, split, or alter any fields, wording, field order, logic, instructions, or declarations from the existing form.

Your job is to build what happens after the form is completed.

PROJECT OBJECTIVE

When a client completes the existing horse submission form, the system must:

1. save the completed form submission in the database
2. generate a clean downloadable PDF version of the completed form
3. save that PDF automatically using the client’s name and the horse’s name in the file title
4. send the submitted form data to an internal ChatGPT-style content engine
5. generate all required horse sale ads and social media content from the submitted information only
6. store the AI-generated outputs against that horse record in an internal admin dashboard for review and editing

CRITICAL RULES

1. The form content is already approved and must remain exactly as it is.
2. The system must preserve the raw original submission exactly as entered by the client.
3. AI outputs must be stored separately from the raw submission data.
4. The AI must never invent facts.
5. If information is missing from the form, the AI must leave it out rather than guess.
6. The system must be easy for a non-technical admin team to use.

WORKFLOW REQUIRED

STEP 1. FORM SUBMISSION
When the seller submits the existing horse submission form:
- save all field values exactly as submitted
- save all uploaded files
- create a unique horse submission record
- record submission date and time
- set status to: New Submission

STEP 2. PDF GENERATION
Immediately after submission, automatically generate a PDF version of the completed form.

PDF requirements:
- the PDF must show the completed form in a clean, readable format
- preserve the original form headings and field labels
- include all submitted answers
- include references to uploaded media, and if practical include image previews or thumbnails
- be suitable for download by admin staff
- be stored against the horse record in the database or file storage

PDF file naming convention:
- use the client name and horse name
- example format:
  ClientName_HorseName_Submission.pdf
- also include a fallback if one of those fields is missing
- sanitise file names so they are safe for storage and download
- if needed, use a format like:
  ClientName_HorseName_YYYYMMDD.pdf

STEP 3. INTERNAL AI CONTENT GENERATION
After the form is submitted, send the structured form data to an internal AI content engine using OpenAI or equivalent.

This internal AI tool is for staff use only. It is not customer-facing.

The AI must use only the information that was submitted in the form.

The AI must generate the following outputs:

1. Master horse sale ad
- polished
- warm
- professional
- premium
- easy to read
- suitable for the main website or direct buyer communication

2. Short sale ad
- shorter version for tighter listing spaces

3. ProHorseMatch version
- tailored for the ProHorseMatch app
- concise and appealing
- easy to scan quickly

4. Social media post caption
- suitable for Facebook and Instagram
- professional and engaging
- sales-focused without hype

5. Additional short social caption variations
- at least 3 alternate shorter caption options

6. Key selling points
- bullet-point summary of the horse’s main highlights

7. Buyer suitability summary
- short summary of the type of rider or buyer this horse may suit
- must only reflect what was actually provided in the form

8. Hashtags
- relevant horse sale and equestrian hashtags
- not spammy
- platform-appropriate

9. Reel brief
- create a brief for a reel or slideshow using the uploaded media
- include suggested image order
- suggested opening hook
- short on-screen text
- suggested CTA
- suggested caption
- suggested style or mood

AI CONTENT RULES

The AI must:
- never invent breeding details
- never invent competition history
- never invent temperament claims
- never invent rider suitability claims
- never invent veterinary or soundness claims
- never exaggerate
- never assume facts that are not in the form

Tone of writing:
- polished
- trustworthy
- warm
- premium
- horse-savvy
- clear
- not cheesy
- not overblown
- not full of clichés
